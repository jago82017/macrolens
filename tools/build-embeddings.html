Build precomputed AI text embeddings

Run this after editing js/fooddb.js or the prompt tables in js/ai.js. It encodes every built-in prompt with the same MobileCLIP-S0 text tower the app uses, then downloads mcs0-text-v1.json and mcs0-text-v1.bin. Put both in /models/ and bump VERSION in sw.js.

Serve the project over http(s) (not file://). Expect several minutes: the text tower is single-threaded WASM.
